2022Java → JavaScript

Cloth simulation

A 3D mass-spring cloth solved with Verlet integration and structural, shear and bend springs, shaded in a WebGL shader with the spring network drawn on top. I first built it in Java, drawn by my own rendering engine on top of Swing's 2D graphics. This web port lets you grab, throw, tear, re-pin and orbit it.

Procedural glass shatter

Breaks any polygonal pane into shards around the impact point using concentric fracture rings and radial cracks, then triangulates each shard with ear clipping into its own EditableMesh. The web demo adds a bond network that decides which shards fall.
